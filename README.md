Spring Boot REST API – Task Management System

Tech Stack: Java, Spring Boot, Spring Data JPA, MySQL, Maven

Developed a RESTful web application to manage tasks with full CRUD functionality.

Designed layered architecture (Controller → Service → Repository) following best practices.

Integrated MySQL database using Hibernate ORM for persistent storage.

Implemented REST endpoints using GET, POST, PUT, DELETE methods and tested via Postman.

Configured application properties and dependency management using Maven.

Ensured proper exception handling and maintained clean package structure.

Key Learning: Backend development, REST APIs, database integration, MVC architecture.
